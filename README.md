# 🧮 Python Calculator

A simple command-line calculator built with **Python**.
It supports basic arithmetic operations including addition, subtraction, multiplication, division, powers, and remainders.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* ** Power
* % Remainder
* Prevents division by zero
* Simple command-line interface

## 🚀 How to Run

Make sure you have **Python 3** installed.

1. Clone or download the project.
2. Open a terminal in the project directory.
3. Run:

```bash
python calculator.py
```

## 📖 How to Use

When you start the calculator, you'll be asked to enter two numbers:

```text
calculator
Enter first number: 10
Enter second number: 5
enter symbol: *
```

The calculator will then perform the selected operation:

```text
The operation is: multiplication
--------------------------
50
```

## 🔢 Supported Operations

| Symbol | Operation      | Example            |
| ------ | -------------- | ------------------ |
| `+`    | Addition       | `10 + 5 = 15`      |
| `-`    | Subtraction    | `10 - 5 = 5`       |
| `*`    | Multiplication | `10 * 5 = 50`      |
| `/`    | Division       | `10 / 5 = 2.0`     |
| `**`   | Power          | `10 ** 5 = 100000` |
| `%`    | Remainder      | `10 % 5 = 0`       |

## 🛡️ Error Handling

The calculator checks for division by zero:

```text
You cannot divide by '0'.
```

This prevents the program from crashing when attempting to divide by zero.
